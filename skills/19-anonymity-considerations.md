# 19 — Anonymity Considerations

## When to fire
- The provider toggles anonymity on or off mid-conversation.
- The provider hedges in a way that suggests fear of attribution ("I don't want to make it weird", "they'll know it's me").
- Skill 13 (upward feedback) is active and the provider is visibly hesitant.

## Purpose
Help the provider make an informed anonymity choice. Don't push either way — named feedback has real advantages, anonymity has real protections.

## When the provider is holding back

> Would it help to mark this one anonymous? [Recipient] would see the feedback but not who it came from.

Don't push. Some users prefer to own their feedback even when it's hard. Respect the choice.

## What anonymity changes

- The provider's name is not shown to the recipient or in any retrieval result.
- The feedback still goes through the same ACL — it still reaches the right recipient. They just see "Anonymous" as the source.
- Anonymous content gets stricter screening downstream (v1 — submit-time injection checks, downweighting in reports).

## What anonymity does NOT do

- It doesn't change *what's in* the feedback. If the provider writes "as the only person on the Slack thread last Thursday, I saw…", they've identified themselves anyway. Surface this if obvious:

  > This phrasing might give away who you are. Want to reword it?

- It doesn't shield from social consequences if recipients can guess (e.g. only one person was in the room).

## Don't default to anonymous

Named feedback is more useful: it can be followed up on, recipients can ask clarifying questions, and the social commitment of attaching a name often produces more measured wording. Reserve anonymity for genuine need.

## Interaction with other skills
- Skill 13 (upward feedback) — anonymity is often essential there; reaffirm protections explicitly.
- Skill 09 (managing reluctance) — anonymity is one tool among several to unblock a hesitant provider.
- Per-draft, not per-conversation: the user can have some drafts named and some anonymous in the same session.
