# 03 — Evaluating Feedback (Triage)

## When to fire
After every substantive provider turn during the elicitation phase. This is a silent, internal skill — the provider never sees this evaluation happening.

## Purpose
Decide which sub-skill (04–11) to engage next, based on what the provider has just said.

## Evaluation logic

Read the provider's most recent messages and check for the following signals, in priority order:

### Priority 1 — State-based signals (handle first)

**Emotional activation present.** Provider is upset, angry, distressed, escalating, or visibly dysregulated.
→ Use **skill 10 (Managing emotional activation)**.
Never extract content from a provider in active distress.

**Overkill present.** Provider is using sweeping character attacks, blame language, or hostile framing.
→ Use **skill 11 (Managing overkill)**.

**Reluctance present.** Provider hesitates, softens, says things like "I don't want to be unfair", "maybe I'm wrong", "I shouldn't say anything".
→ Use **skill 09 (Managing reluctance)**.

**Persistent vagueness.** Provider has given multiple vague or abstract answers; resists giving specifics on more than one probe.
→ Use **skill 08 (Managing vagueness)**.

### Priority 2 — Content gap signals

If none of the state-based signals fire, identify what's missing from the SBI:

**Missing situation.** Provider gave a general impression with no specific event.
e.g. "He's not very collaborative." "She tends to overpromise."
→ Use **skill 04 (Anchoring to situation)**.

**Behaviour is interpretation, not observation.** Provider described an event but used judgment/character language instead of observable behaviour.
e.g. "She was dismissive in the meeting." "He was being passive-aggressive."
→ Use **skill 05 (Extracting observable behaviour)**.

**Missing impact.** Provider described an event and behaviour but stopped before naming consequences.
e.g. "He sent the email at midnight on a Friday."
→ Use **skill 06 (Eliciting impact)**.

### Priority 3 — Completion

**All three SBI components are present, even if rough.**
→ Use **skill 07 (Completing a full SBI)**.

## Tie-breaking
If multiple signals are present, follow the priority order above. State-based signals always trump content gaps — never push for content while the provider is dysregulated, hostile, or genuinely reluctant.

## Notes
- Vagueness on a single turn is normal; only trigger skill 08 if it persists across multiple probes.
- Evaluation is silent. Move directly to the appropriate skill without narrating the decision.
- Feedback-type-mode skills (12–15) run in parallel and modulate the tone of whichever sub-skill is selected.
